# Mailroom

A better mailbox for WoW 1.12. Needs [ClassicAPI](https://github.com/brues-code/ClassicAPI).

- **Open All** takes every mail's money and items in one click.
- **Send many items** at once: right-click bag items while the mailbox is open.
- **Names complete** as you type. Press Tab to cycle.

## Install

Download `Mailroom.zip` from [Releases](https://github.com/Fostercare5988/Mailroom/releases/latest) and unzip it into `Interface\AddOns`.

Based on [TurtleMail](https://github.com/sica42/TurtleMail) by shirsig and sica42.
